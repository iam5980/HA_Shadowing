# HA_Shadowing — 跟讀小教練

Howard 與 Audrey 的英文跟讀與單字發音練習網頁（iPad / iPhone Safari）。

- 網址：https://iam5980.github.io/HA_Shadowing/
- 句子跟讀：示範 → 跟讀 → 逐字標色、分數與星星、錯字重練、回放錄音
- 單字練習三種模式：
  - 跟讀發音：先聽發音 → 自動錄音 → 0–100 分，可反覆練到 100 分（可顯示中文）
  - 英翻中：看英文，四選一選出中文意思
  - 中翻英（用說的）：看中文，直接說出英文，以發音辨識評分
- 依難度（CEFR：Pre-A1、A1、A2、B1、B2、C1）篩選字表
- 自己貼：貼上句子或單字即可練習

## 單字題庫（words.js）
- 劍橋英檢五級：Starters 410、Movers 357、Flyers 470、A2 Key 589、B1 PET 1,385 字（共 3,211 字）
- 同一路線內每個字只放在最早出現的等級（劍橋、全民英檢、Oxford 三條路線各自獨立）
- 中文釋義：取自 LTTC 全民英檢參考字表；字表中查無的字另補譯註；已排除冠詞、代名詞、be 動詞等功能字與 YLE 人名；每 20 字一包
- 字表由官方 PDF 經網頁讀取工具分段擷取，A2 Key 可能缺少數十字，待取得原始 PDF 後逐字比對補齊
- Oxford 5000（CEFR A1–C1）：A1 821、A2 785、B1 688、B2 1,295、C1 1,277 字，補足 B2（FCE）與 C1（CAE）程度
- 學術字彙 AWL（Coxhead）：Sublist 1–10，共 570 個詞族字首（大學、托福、雅思）
- 全民英檢：初級 2,092、中級 2,549、中高級 3,083 字（共 7,724 字），由 LTTC 官方中高級參考字表（2026/08/21 修訂）依級數欄位分級，完整解析
